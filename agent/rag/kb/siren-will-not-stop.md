---
title: Siren will not stop
device_type: control_panel
symptoms: alarm going off, siren wont stop, loud alarm, cannot silence alarm, alarm keeps sounding
---

This is urgent for the caller. Deal with the noise first and the cause after.

1. Go to the panel and enter your four digit alarm code.
2. If the siren does not stop, enter the code once more, slowly.

If the code is not stopping it:

3. Tell me whether the panel display is showing anything.
4. If the panel is blank, it has lost power and the siren is running on its backup battery.
5. Check that the panel's power cable is pushed fully into the wall socket.
6. Check whether that socket is switched on, and whether it is controlled by a light switch.

If the code works but the siren starts again shortly after, a sensor is
repeatedly triggering. The panel will name which one. That sensor needs
attention, and the system can be disarmed until it is sorted.

Never advise a caller to cut power to the panel or remove its backup battery.
