---
title: System shows not ready to arm
device_type: control_panel
symptoms: not ready, cannot arm, system not ready to arm, wont set, something is open
---

The system refuses to arm when it believes a door or window is open, and it
will name what it thinks is open.

1. Read me what the panel names as open.
2. Go to that door or window and check whether it is properly closed.
3. If it is a window, check that it is fully shut rather than on a latch.

If it is closed but still shows open:

4. The two halves of the sensor are probably too far apart. When the door is
   closed they should be within about half an inch of each other.
5. If the gap looks larger, the sensor or its magnet has shifted and needs
   repositioning.

Most panels allow you to bypass a sensor and arm anyway. Explain clearly that a
bypassed door or window will not be monitored while the system is armed.
